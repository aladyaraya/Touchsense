## 接手建议

- Android 开发：解压 `02_Android_MVP/TouchScene_Android_MVP_20260922_r9.zip`，先看其中的 `docs/verification-r9.md` 和 README，再配置本机 Android/Gradle 环境。包内排除了本机配置、构建缓存、keystore 与真实凭据；不要把别人的密钥加入共享目录。
- 真机测试：按 `03_实体连接性测试/测试说明.md` 先跑官方 Demo，再跑 TouchScene；记录失败也很有价值。采集器不自动判断 Gate，屏幕影像和观察记录要另存。
- Web/ESP32：Web 页面可从 `04_Web与硬件原型/web/index.html` 查看，但 Web Bluetooth 需要合适的安全上下文；ESP32 固件编译通过不等于已物理联调。硬件操作前核对 BOM、供电与安全说明。

旧版 r2–r8 和 StoryBean/FrameFit 等其他项目未混入交接包。若确需追溯旧版本，请到原仓库的 `实际开发/交付包/` 查找。不要把本包内“模拟通过”或“软件实现”转写成“实体测试通过”。
