# TouchScene 当前实现与待办总结

更新日期：2026-09-22。范围：TouchScene Ace Pro 2 Android MVP v1.1，同时简述已有 Web/ESP32 原型。本文依据当前主工程、r9 交付快照及验收审计整理；**不是实体设备通过报告**。

## 一句话结论

Android MVP 的相机流接入、双链路处理、64×48 触觉图、冻结探索、语音描述/控制、拍摄回调和 READY 提示等**软件实现已基本齐备，并通过离线与模拟器回归**。目前最大缺口不是继续堆功能，而是用指定 Ace Pro 2 与目标 Android 手机完成连接、画面/触觉/语音/拍摄、性能和无障碍的实体验收；正式签名交付需在验收与调参后完成。

## 状态口径

- **已实现且软件验证**：主工程有对应代码，并有单元测试、模拟器测试或构建证据；不代表真机效果达标。
- **已实现、待实体验证**：已有功能链路，但 Ace/手机/振动器/真实用户上的行为和指标尚无证据。
- **待开发或调优**：需要真机结果驱动的参数/兼容性修正、正式发布工作，或首版未覆盖的产品能力。
- **明确不属于 v1.1 MVP**：方案第 26、37 节主动排除的扩展，不能算当前首版欠交付。

## 已实现的部分

| 模块 | 当前实现 | 已有证据与边界 |
|---|---|---|
| Android 基础与 Ace SDK | 基于 Insta360 SDK Demo 2.1.5 的原生 Views/ViewBinding 项目，保留连接、预览、拍摄及前台服务；按时间戳聚合预览分片，动态选择 H.264/H.265 `MediaCodec` 解码 YUV。超大帧整时间戳丢弃，停流/失败逐项清理并处理关闭竞争。 | 编码、生命周期与异常路径有 JVM 回归；**尚未在指定 Ace 固件与手机上证明连接、首帧、连续预览及断连恢复**。 |
| 并行实时处理 | 同一解码帧进入独立 Vision 与 Edge 最新帧通道；慢语义推理不会阻塞触觉图处理，也不建立无界帧队列。 | 并行、慢任务与线程池关闭拒绝任务有软件测试；真实 Ace 下 5–10 Hz Edge 吞吐未测。 |
| 轮廓与触觉图 | 可配置缩放/高斯/Canny/闭运算/轮廓过滤，受控 Otsu 回退；输出 64×48 背景、主体、边界、关键点图，保留宽/竖幅比例和留白。关键点限制在真实主体格。预览可切换原图和处理中间层。 | 矩形、圆形、人物/不规则、空图、凹形与比例素材测试通过；真实场景质量、SDK 播放器裁剪与地图配准未测。 |
| 冻结与探索 | 探索时冻结图及原始源帧；相机运动只将图标为过期，刷新必须有更新版本；接触期间不换图。中心适配/留白坐标映射、抬手越界和多指取消均有处理；可返回实时模式。 | API 35 模拟器覆盖 100 点 View 坐标、留白、多指、冻结和本地演示；实体触屏 100 点与 30 次边界跨越未测。 |
| Android 触觉 | 背景静默、主体低占空比循环、边界单次约 150 ms 长震、关键点双脉冲；边界冷却、多指、抬手、取消、暂停、停流均有停止逻辑。 | 波形和状态门有 JVM 回归；真实振动器起停时延及四种节奏可辨性未测。单马达只能提供全局振动标签，不能产生局部凸点。 |
| 场景描述与播报 | APK 内本地 ML Kit 标签模型 + 同帧轮廓几何，中文词表过滤；超时或无合适标签时明确回退。支持按需描述、同帧缓存、LIVE 状态下最多每 5 秒自动分析与有意义变化播报；TTS 可打断旧播报。 | 请求超时/取消/缓存/新旧帧匹配有回归；目标手机上的标签准确率、中文覆盖、推理时延、听感和离线效果未测。 |
| 语音控制与稳定提示 | SpeechRecognizer 六条白名单；TTS/ASR 半双工防回声；无相机状态拒绝语音拍摄。视频帧差稳定检测 + SDK 四向姿态旋转，稳定一段时间后每段稳定状态仅提示一次 READY。 | 命令、模式切换、READY 冷却有软件测试；真实麦克风、语音包、相机运动阈值和 READY 感知未测。首版 Guide 仅表示“稳定可拍”。 |
| 拍照/录像 | SDK 拍摄/录像状态链路、模式切换失败回退；完成或错误回调一次性终态门，只有完成回调后才播报成功。录像开始也等待 SDK 工作/计时回调。 | 回调乱序、迟到成功、失败与重复分派有 JVM 回归；Ace 真机拍摄结果、回调顺序和故障注入未测。 |
| 无障碍与降级 | TalkBack 可聚焦的方向按钮按冻结图报网格位置/类别；无相机本地演示沿用生产 Canny/TouchMap 链路且禁用拍摄；浏览器 PWA 作为独立备用演示。 | 本地演示在模拟器走通；实体 TalkBack 焦点、播报与振动体验未测。演示素材不等于 Ace 实时画面。 |
| 诊断与交付 | 元数据 `TouchSceneTrace`/JSONL、最近 64 图的 FPS/P95 性能窗口、真机采集脚本、Gate 执行稿、r9 源码/APK 交付包和单独的连接性测试资料包。 | 日志在模拟器落盘，采集器通过假 ADB 自测及无真机/模拟器拒绝检查；**真实手机采集路径未验证**。 |

### 已完成的软件验证

最新可复核交付为 `交付包/TouchScene_Android_MVP_20260922_r9.zip`。主工程与独立交付副本均通过 **69/69 JVM 测试、6/6 API 35 模拟器仪器测试、Debug/未签名 Release/测试 APK 构建**；`lintDebug` 为 **0 错误、101 警告**。r9 中 214 个 `app/src` 文件与主工程逐项 SHA-256 一致，ZIP 237 个条目逐项哈希核验无差异；ZIP SHA-256 为 `B8388A7D14B029CE4AE3551BF67AA688604546324A6E6819F7DE5821B7F63404`。这些数字只说明**软件构建与模拟器回归**，不是 Ace、实体触觉或真实用户验收。

Web/PWA 原型另有照片输入、64×48 地图、浏览器振动和 Web Bluetooth 协议链路；7 项 Node 核心测试及浏览器 Mock 100/100 坐标检查通过。ESP32-C3 固件在启用/关闭可选 SW-420 传感器两种配置下编译通过。Mock RTT、模拟 ACK 和固件编译都**不能证明真实 BLE 时延或马达动作**。Android v1.1 MVP 不依赖外接 ESP32。

## 首版明确不做与后续产品方向

v1.1 详细方案明确不实现 Detection ROI、语义分割、人体姿态、人脸身份、目标框或左右构图引导、自动审美评分、导航避障、外接 ESP32 和开放式 LLM 对话。首版 Guide 只做稳定检测与 READY，不是完整构图导航。这些属于**后续版本候选**，不是本轮软件缺陷。

更远期的“描述 → 探索 → 选择主体 → 引导构图 → 确认拍摄”完整产品闭环，尚缺显式主体选择、方向引导、构图指标，以及面向盲人和低视力用户的研究验证。应在 MVP 真机链路和使用场景明确后再定义需求，避免把未来愿景误写成 v1.1 已实现功能。
