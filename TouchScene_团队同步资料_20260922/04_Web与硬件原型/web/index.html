安卓 Chrome 通过 navigator.vibrate() 输出节奏。强度是否可控取决于机型，因此本 Demo 用节奏区分触觉语义。

每个数据包携带序号、坐标、状态与 XOR 校验。接入可选振动传感器后，ESP32 只有检测到实际振动才回传“物理确认”。
