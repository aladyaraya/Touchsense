## 安装前必须知道

两个 APK 都声明包名 `com.insta360.kmpsdk.demo`、最低 Android API 29；签名证书 **不同**：官方 Demo SHA-256 `c609ad0fdd67267afac11ab3a70a23aad2f9025bd3cd1a2df3be9bc9aa0fa06c`，TouchScene SHA-256 `cfe95f70396217f73bb6b79f2f2321983c0197efd55b2321aa3e4f197e513b9a`。它们不能共存，也不能直接覆盖。请优先使用专用测试手机。切换前保存照片、日志、设置等需要保留的数据，再**由你确认**是否执行 `adb uninstall com.insta360.kmpsdk.demo`；此操作会清除该应用及其数据。若现有同包名应用的数据不能清除，就先暂停，不要卸载。不要用 `-r` 或强制降级绕过签名冲突。

安装包均为 Debug；r9 Release APK 尚未签名，不用于本次安装。厂商 Demo 可用也不能替代 TouchScene 真机通过。

## 建议测试顺序（Windows PowerShell）

1. 准备 Ace 准确型号/固件、Android 手机、数据线、已授权 USB 调试、Android SDK `platform-tools` 的 `adb.exe`。从本目录打开 PowerShell，运行 `adb devices -l`，确认目标手机显示为 `device`，不是 `unauthorized`、`offline` 或 `emulator-*`。若 `adb` 不在 PATH，用 `& '你的platform-tools\adb.exe'` 代替。记录手机和相机信息。
2. 如测试手机上没有同包名应用，运行 `adb install .\apk\Insta360-SDK-Demo-2.1.5.apk`。如已有，先确认旧数据能否清除。打开官方 Demo，连接 Ace，确认 SDK 预览持续显示真实画面并拍照。把状态、时间、错误码、截图或录像填入模板。官方 Demo 失败时先停止 TouchScene 对比，保留错误信息。
3. 保存官方 Demo 所需数据后，决定是否运行 `adb uninstall com.insta360.kmpsdk.demo`，再运行 `adb install .\apk\TouchScene-debug-r9.apk`。卸载或安装失败就记录原始输出，不要反复清理数据。
4. 在 TouchScene 中“连接 Ace → 开始预览”，核对真实画面和 `preview.start_requested → preview.stream_opened → decoder.first_frame → map.state_live` 顺序。记录持续预览、断连、重连及再次首帧。内置“无相机本地演示”**不算** Ace 连接通过。
5. 完成 TouchScene 操作后运行下面的采集命令；另存屏幕录像/截图、相机状态和手工记录。采集器只筛 `TouchSceneTrace`，不能代替观察真实画面。

```powershell
$adb = '你的platform-tools\adb.exe'
& $adb devices -l
$serial = 'adb devices -l 中目标实体手机的序列号'
$out = Join-Path (Get-Location) ('TouchScene-evidence-' + (Get-Date -Format 'yyyyMMdd-HHmmss'))
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\collect_touchscene_android_gate.ps1 -AdbPath $adb -Serial $serial -ApkPath .\apk\TouchScene-debug-r9.apk -OutputDirectory $out
```

采集器会创建全新目录，包含设备信息、APK 哈希、筛选日志及可取得时的 JSONL；它明确写 `gate_result=not_assessed_by_collector`。多个实体手机同时连接时必须填写 `-Serial`。不要把脚本的假 ADB 自测当作连接证据。

## 通过条件与交接

仅在官方 Demo 的连接/预览/拍照与 TouchScene 的连接/真实首帧/地图、断连/重连分别被实体观察，并有对应时间和日志/影像时，才能把相应项目标为“通过”。失败或未执行就如实填写。连接性通过也**不等于**触觉、TalkBack、10 分钟热稳定或用户验收通过；这些仍按完整 Gate 执行稿单独测量。

完成后可把填好的 `连接性测试记录模板.md`、`TouchScene-evidence-*` 目录及必要截图/录像交回；日志可能含设备序列号，分享前按需要脱敏，保留原始证据备查。
